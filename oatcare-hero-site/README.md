# OatCare 힉스필드 웹사이트 — 코드 사본

이 폴더는 힉스필드 웹사이트 빌더로 만든 `oatcare.higgsfield.app` 사이트에서
**제가 직접 작성한 커스텀 코드**만 모아둔 사본입니다.

## 왜 "전체" 코드가 아닌지

이 사이트는 React 19 + TanStack Start + Cloudflare Workers 기반으로,
힉스필드가 제공하는 대형 템플릿(빌드 설정, 스크롤 스크럽 엔진, 수백 개의
공용 컴포넌트 라이브러리 등 수천 개 파일)을 뼈대로 하고 그 위에 저희 브랜드
코드를 채워 넣는 구조입니다.

- 실제 실행 가능한 전체 프로젝트(템플릿 전체 + 빌드 설정 + 이미지/영상 원본
  파일들)는 힉스필드 계정에 연결된 비공개 저장소에만 있고, 제 작업 환경에서
  그 저장소 서버(apps-repos.higgsfield.ai, CloudFront 자산 서버)로 직접
  접속이 막혀 있어서 대용량 파일(사진/영상)까지 이 폴더로 그대로 복사해
  드릴 수는 없었습니다.
- 대신 제가 이번에 새로 작성한 **텍스트 코드 파일**은 전부 여기 그대로
  옮겨 담았습니다. 아래 "포함된 파일" 참고하세요.

## 포함된 파일

- `design-brief.md` — 디자인 기획 문서 (컨셉/팔레트/타이포/섹션 구성)
- `scroll-scrub-scenes.ts` — 히어로 스크롤 영상 4개 챕터 텍스트/설정
- `app-meta.json` — 사이트 제목/설명/OG 이미지 설정
- `styles-oatcare-tokens.css` — 브랜드 색상/폰트 토큰 (styles.css 끝에 추가된 부분만)
- `components/sections.tsx` — 실제 섹션 컴포넌트 전체 (Nav/제품그리드/영양정보/번들/CTA 등)
- `components/site.css` — 위 컴포넌트들의 스타일
- `routes/index.tsx` — 홈페이지 조립 코드
- `routes/root-patch-notes.md` — `__root.tsx`(힉스필드 템플릿 공용 파일)에
  적용한 4곳의 수정 내역 — 이 파일 자체는 대형 템플릿 파일이라 전문을
  옮기지 않고 변경한 부분만 정리했습니다.

## 실제 사이트 이미지/영상

제품 사진 5장, 히어로 영상, 아이콘, 로고, OG 카드 등은 전부 힉스필드
저장소 안 `app/public/assets/`에 실제로 들어가 있고 배포된 사이트에서
정상적으로 서빙됩니다. 다만 위와 같은 이유로 그 원본 파일들을 이 폴더로는
받아오지 못했습니다. 필요하시면 힉스필드 계정에 로그인해서 직접
다운로드하시거나, 제가 다른 방법(예: 사장님이 각 파일을 브라우저로 열어서
저장)을 안내해드릴 수 있습니다.
